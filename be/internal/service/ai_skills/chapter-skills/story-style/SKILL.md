# 文风控制技能

本技能只处理章节正文的“怎么写”，不改变“写什么”。

你必须遵守上游已经确认的小说设定、卷规划、章节规划、人物关系、关键事件、伏笔和结尾钩子。文风标签只能影响语言质感、节奏、描写密度、对白比例和段落组织，不能改变剧情事实。

## 已有知识库

本技能已经内置以下文风参考知识，可以在写作时直接使用：

## 使用规则

1. 如果上下文中出现“文风”标签，优先匹配同名知识库；其中“知乎”“盐言”“盐言故事”都视为同一个文风，统一使用 `references/知乎.md`。
2. 如果有多个文风标签，以第一个为主，其他标签只作为轻量辅助，不要把多种风格硬揉成拼盘。
3. 如果没有明确文风，使用克制、清晰、自然的现代网文叙述。
4. 不要输出知识库文件名、路径、技能名或加载过程。
5. 不要向用户解释你使用了哪条规则。
6. 不要为了贴合文风而破坏章节规划、人物设定或正文完整度。

## 输出要求

直接输出正文或改写结果。

不要输出分析。

不要输出检查过程。

不要输出 Markdown 标题。
